Download & Installation

DriveLab herunterladen, installieren und für deine erste Simulation vorbereiten.

1. DriveLab herunterladen

Die verfügbaren Versionen findest du im offiziellen GitHub-Repository:

Offizieller Download

GitHub Releases ↗

Windows-Installer und Informationen zur aktuellen Version ansehen.

Öffne den gewünschten Release und lade im Bereich Assets den passenden Installer herunter, beispielsweise eine Datei mit dem Namen DriveLab-*-win64.exe.

Alpha-VersionDriveLab befindet sich in einer frühen Entwicklungsphase. Funktionen und Dateiformate können sich zwischen Versionen ändern.

2. Systemanforderungen

Aktuell wird ein Installer für Windows (64 Bit) angeboten. Weitere Plattformen sind damit nicht automatisch unterstützt. Zusätzliche Abhängigkeiten und Anforderungen richten sich nach dem jeweiligen Release.

3. Installieren

Starte den heruntergeladenen Installer und folge den Schritten des Installationsassistenten. Die Standardinstallation erfolgt im Benutzerkontext und benötigt keine Administratorrechte.

Hinweis zur Windows-SicherheitsmeldungDer Installer ist derzeit nicht digital signiert. Windows SmartScreen kann deshalb eine Warnung anzeigen. Prüfe vor dem Start, ob du die Datei aus dem offiziellen DriveLab-Repository bezogen hast. Führe keine Dateien aus unbekannten Quellen aus.

4. Lizenz

Für die Ausführung von Simulationen benötigst du eine gültige DriveLab-Lizenz (license.lic). Die Lizenz wird im Arbeitsordner abgelegt; alternativ kann der Pfad über DRIVELAB_LICENSE angegeben werden. Eine Lizenz ist nicht Bestandteil des öffentlichen Downloads.

Falls du noch keine Lizenz hast, kontaktiere den Projektbetreiber über das GitHub-Repository. Ein automatischer Lizenzbezug ist in dieser Dokumentation derzeit nicht beschrieben.

5. Installation prüfen

Öffne nach der Installation ein neues Terminal und führe aus:

Eingabeaufforderung
drivelab --version
drivelab license
drivelab docs

Mit drivelab docs kannst du weiterhin die lokal installierte Dokumentation öffnen – auch ohne Internetverbindung.
