Handbuch 0.2.2

DriveLab

Fahrdynamik-Simulation zum Selberbauen: Fahrzeugmodelle aus austauschbaren Komponenten, virtuelle Steuergeräte am CAN-Bus, Strecken aus JSON oder OpenDRIVE – gesteuert über die Kommandozeile oder aus Python.

DriveLab ausprobieren

DriveLab ist aktuell als Alpha-Version für Windows verfügbar. Lade den Installer herunter und folge der Installationsanleitung. Für Simulationen ist eine gültige Lizenz erforderlich.

Was DriveLab kann

Modellieren

Fahrzeug aus Komponenten

Einspur-, Zweispur- oder MKS-Modell; Reifen, Antrieb, Bremse, Aero, Federung und Kinematik je als eigene Datei – auch als FMU.

Regeln

Virtuelle Steuergeräte

Eigene Steuergeräte als DLL an einem oder mehreren CAN-Bussen nach DBC, gebaut mit dem mitgelieferten SDK. Fahrzeuglogs lassen sich als Bussignale abspielen.

Auswerten

Reports

HTML-Report je Lauf mit Bus-Mitschnitt, dazu Einzelreports für jede Komponente und das ganze Fahrzeug.

Skripten

Python

Simulation Schritt für Schritt aus Python fahren, Sensoren auslesen, Strecken laden und abtasten.

Wie ein Lauf zustande kommt

config.jsonwählt Fahrzeug, Strecke, Fahrer, Sensoren
→
FahrzeugModell + Komponenten + Steuergeräte-Netz
→
drivelab runrechnet bis t_end oder bis das Fahrzeug die Strecke verlässt
→
results/run_NNNZeitreihen, Bus-Mitschnitt, Log
→
drivelab reportHTML-Report

Alle Eingaben sind JSON-Dateien (Strecken auch .xodr), alle Ergebnisse Text-Tabellen. Beides lässt sich versionieren und mit jedem Werkzeug weiterverarbeiten.
