Das Modul drivelab steuert eine Simulation Schritt für Schritt aus Python: Befehl rein, Zustand, Sensoren und Straßenbezug raus. Dazu kommt eine Straßen-API zum Laden, Abfragen und Abtasten von Strecken.

Beispiele

Im Arbeitsordner unter Dokumente/DriveLab/examples/python. Der Installer legt sie dort an; eigene Änderungen überschreibt ein Update nicht. drivelab_path.py verweist auf die Installation und wird bei jedem Update neu geschrieben.

Die Beispiele nehmen die config.json eines Projekts – Fahrzeug, Strecke und Sensoren kommen von dort. Ohne Angabe nutzen sie die Vorlage aus dem Installationsordner, dann ohne Ergebnisordner. Die Vorlage fährt geradeaus; Kurven zeigt "road": "./data/roads/einfacher_Rundkurs.json" in der config.json.

Einrichtung

Das Modul liegt in python im Installationsordner und ist für eine bestimmte Python-Version gebaut; sie steht im Dateinamen, z. B. drivelab.cp313-win_amd64.pyd = Python 3.13. Mit einer anderen Version schlägt import drivelab fehl.

Simulation

Python
config = Path.home() / "Documents" / "DriveLab" / "projects" / "MeinProjekt" / "config.json"
env = drivelab.make_env(str(config))

obs = env.reset()
while True:
    result = env.step(drivelab.Action(0.0, 0.3, 0.0))   # Lenkwinkel, Gas, Bremse
    if result.done:
        break

make_env legt wie drivelab run einen Ergebnisordner an. Mit make_env(config, artifacts=drivelab.RunArtifacts.Disabled) entsteht keiner – für Experimente und für Konfigurationen in schreibgeschützten Ordnern. Ein step rechnet einen Schritt sim.dt. Die Fahrerdatei der Konfiguration bleibt ungenutzt – der Fahrer ist dein Python-Code.

Sensoren – SensorFrame

Jeder Sensor misst in seinem eigenen Takt; dazwischen bleibt die letzte Messung stehen, timestamp zeigt, wann sie entstand.

Stolperfallen

  • env.sensors() gilt bis zum nächsten step. Was du behalten willst, in eigene Variablen kopieren (wie read_signals in pov_sensor.py).
  • step oder step_direct: Mit Steuergeräte-Netz kommt ein Befehl aus step verzögert und begrenzt an. plant_inputs() zeigt, was tatsächlich ankam.
  • Fahrzeugmodell wechseln ändert die Namen in state_names(). Per Namen zugreifen, nicht per Index.
